# VELOOP Rewards — Watch Ads

A modern, responsive ad-watching rewards dashboard built with React and Vite. Users can watch demo ads and earn VE tokens using interactive UI features.

## 🚀 Live Demo

https://v-eloop-watch-ads.vercel.app/

## ✨ Features

- Daily earnings progress and animated hero section
- Animated statistics and earnings cards
- Six ad cards with reward badges and status indicators
- Interactive watch buttons with countdown and completion states
- Reward success modal and confetti animation
- Daily streak, recent earnings timeline and weekly chart
- Filter and sort ad cards
- Responsive dark fintech UI
- Withdraw page UI

## 🛠️ Technology Stack

- React 18
- Vite
- JavaScript
- Bootstrap 5
- CSS Modules
- Lucide React and React Icons


```bash
npm run build
npm run preview
```

This is a frontend demo project using dummy data. Real payments, withdrawals and backend functionality are not connected.
